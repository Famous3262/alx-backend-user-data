# ALX Backend User Data

Backend coursework focused on handling user-related data, authentication, and privacy-aware application development.

## Topics covered

- Personal data handling
- Basic authentication
- User authentication services

## Concepts practised

- Managing sensitive user information responsibly
- Authentication flows and credential handling
- Backend access-control patterns
- Organizing authentication logic in Python services
- Testing user-data and authentication functionality

## Repository structure

The assignments are organized into topic directories, including:

- `0x00-personal_data/`
- `0x01-Basic_authentication/`
- `0x03-user_authentication_service/`

Review each directory for its own task requirements and execution instructions.

## Status

ALX educational coursework. The exercises are learning implementations and should not be treated as a security-audited authentication product.
